# SVAE Tech Website Clone

Files:
- index.html
- style.css
- script.js

Open `index.html` directly in a browser.

The implementation is based on the supplied screenshots and is responsive for desktop/tablet/mobile.

The contact form is frontend-only. Replace the submit handler in `script.js` with your API, Formspree, EmailJS, AWS Lambda, PHP endpoint, etc. when you want actual email delivery.
